## Overview

Filterscape is a spectral filter bank combining up to six filter modules with a modulation sequencer and dynamics section, enabling complex spectral animation and formant-shifting effects.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **u-he Filterscape** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Six Filter Modules** | Stack up to six LP, HP, BP, notch, and comb filters in parallel or series |
| **Mod Sequencer** | Animate filter positions and levels with a step-sequenced modulator |
| **Spectral Dynamics** | Frequency-selective compression and expansion per filter band |
| **XY Control** | XY pad controls multiple filter parameters simultaneously |
